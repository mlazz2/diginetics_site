Product Demo

From client data to auditable decisions. Watch the AWS orchestration run.

This demo follows the same production path we use today: tenant data in S3, DDX discovery on AWS Batch, Elijah orchestration, and a plain-language answer an operator can defend. Example: Capstone Communities commercial real estate portfolio.

Production orchestration (what runs in AWS today)

1
Client data lands in S3 Portfolio CSV and parquet tables sync to the tenant prefix in diginetics-dev-data.
S3 · tenants/capstone/
2
Admin API syncs tenant workspace Lambda pulls raw and prepared data into an isolated tenant workspace before discovery.
Lambda · ensure_tenant_data_synced
3
Elijah cycle prepares and targets metrics Batch job runs ETL, agent loop, and selects the next metric to discover.
Batch · diginetics-dev-demo-elijah
4
DDX discovery run executes Config and observations upload to S3. Batch or Step Functions runs the full DDX pipeline out of sample.
Batch · start_discovery_run
5
Elijah delivers the operator answer Validated equation, sensitivity context, and a brief the portfolio team can use in decisions.
Elijah · private validated library

Example in this demo

Capstone Communities portfolio work on US commercial real estate. DDX pointed at 31 metros and 12 years of monthly data with no hypothesis given. It surfaced a governing equation for months of housing supply that held through COVID, the 2021 boom, 2022 rate hikes, and 2024 normalization.
